# Naming

**Working name:** FlowerScan (folder, package scope `@flowerscan/*`, export folder). Renaming later is cheap
because the export folder name is a setting and package names are internal.

## Decided: separate brand (2026-10-25, open-questions Q1)

FlowerScan is its own brand, separate from Cannapickforme. Cross-promotion stays possible later.
**Roy owns the final name and identity** ([13-creative-brief.md](13-creative-brief.md)). The tech side keeps
the working name until he delivers.

## Candidates

Criteria: says the action, short, easy to spell after hearing it once, no youth appeal, not confusable
with an existing big brand, `.com`/`.app` obtainable.

| Name | Angle |
| --- | --- |
| **FlowerScan** | Literal and clear; "flower" is industry-standard, less slangy |
| **StrainSnap** | Action verb, alliterative; "just StrainSnap it" |
| **KindCheck** | "What kind is it?", a double meaning with "kind bud" |
| **StrainTree** | Leads with the differentiator: the family tree |
| **RootCheck** | Lineage = roots; short and verb-like |
| **PhenoPeek** | Connoisseur flavor; playful |
| **BudTrace** | "Trace the lineage" |

> Domain availability and trademarks have **not** been checked. Before choosing: search USPTO (TESS) and
> state cannabis trademark registries, check `.com` / `.app` availability, and check app-store and social
> handles.
