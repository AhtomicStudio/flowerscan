# Strawberry Banana

## Curator notes
DNA Genetics' own page says it comes from Crockett's Banana Kush crossed with Strawberry Bubble Gum, and calls it a
70:30 indica-dominant hybrid. The Theory page (theorywellness.org) gives "Banana Kush x Bubble Gum", credited to
"DNA Genetics x Serious Seeds", and calls it "an indica strain". The second parent links to the `Bubble Gum` node:
DNA names a strawberry selection of it, which isn't modelled as its own node. DNA's seed listing on the same page
("Original Strawberry Banana x Strawberry Banana") describes its S1 seed product, not the original cross.

`reported_type` follows the breeder (indica-dominant) over Theory's "indica".

Effect tag: `creative` (DNA: "uplifting creativity"; Theory: "stimulating creativity").

**Terms caveat for founders:** DNA Genetics' terms say site content is "for personal use only" (the same open
question as Jeeter in `SOURCES.md`). If founders exclude such sources, drop the DNA source: the parents still rest
on Theory, `reported_type` would become `indica` (Theory's word), and `effects` would be empty.
