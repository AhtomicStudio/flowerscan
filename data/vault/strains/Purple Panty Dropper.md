# Purple Panty Dropper

## Curator notes
Ancestor stub. Mother side of Blueberry Muffin in both sources. Humboldt Seed Company's catalog uses the name in
several of its own lineages, but no page read says who bred it, so `breeder` is empty.

The same catalog has a "P.P.D." entry (indica dominant; Matanuska Mist x Oregon Grape x Purple Haze, no cross order),
which is very likely this plant under a shortened name. I couldn't read a page that says so (the breeder's site was
blocked), so the P.P.D. data isn't used and "P.P.D." isn't an alias yet. The catalog also offers P.P.D. as an
autoflower; any autoflower version is out of scope (P1) and not this node.
