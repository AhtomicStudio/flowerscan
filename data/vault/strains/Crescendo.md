# Crescendo

## Curator notes
An Ethos Genetics strain built from three named plants: Chem Dawg, I-95 and Mandarin Cookies. The three reviews list
them flat ("Chem Dawg x I-95 x Mandarin Cookies") and the Theory page (theorywellness.org) in another order
("I-95 x Chemdawg x Mandarin Cookies"). None says which two were crossed first, so `parents` is `unknown` (modelled
like Jack Herer in T-007) rather than a guessed structure. A breeder source with the cross order would let
this be traced.

Peach Crescendo is a separate Ethos line (it adds Peach Rings per Theory) and is not this node.

`reported_type: sativa-dominant`: Theory's text and three review tags. The Ethos-grown review is tagged sativa
dominant but its text says "Indica dominant hybrid", so it isn't counted for the type.

Effect tags, each in at least two sources: `relaxed` (three sources), `euphoric` (two reviews; one spells it
"euphioric"), `happy` (one review and Theory's "happiness").
