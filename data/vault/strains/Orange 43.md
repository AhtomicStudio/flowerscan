# Orange 43

## Curator notes
Both sources credit Franchise Genetics, but they name the parents differently.

**Parent names are disputed.**
1. **WIFI 43 x Orange Juice Bud** (used here). Willamette Week (2017): the mother is WIFI 43, a clone-only numbered
   plant from a TLC Collective seed run in Los Angeles (the "43" in the name), pollinated by an Orange Juice Bud male.
2. **White Fire 43 x Orange.** Klutch Cannabis (Ohio) gives "(White Fire 43 x Orange)", bred by Franchise Genetics
   and selected by Tahoe_Nugz.

"WIFI" is plausibly short for White Fire, which would make the mothers the same plant, but neither source says so.
"Orange" vs. "Orange Juice Bud" is a real difference in wording. Founders: if a breeder source confirms they're the
same plants, add the Klutch names as aliases and set this back to `unverified`.

Type: Willamette Week calls it an indica-dominant hybrid. Klutch sells it as a sativa but says it has an
"Indica-dominant lineage", so both back `indica-dominant` for the lineage claim.
