# Lilac Diesel

## Curator notes
An Ethos Genetics polyhybrid. Every source names four components, but they disagree on names and none of the
flower sources gives the cross structure:
- Two reviews and Seeds Here Now: "Silver Lemon Haze x Forbidden Fruit x NYC Cherry Pie x Citral Glue" (flat list).
- A rosin review of the **#3** selection: "(Super Lemon Haze x Forbidden Fruit) x (Cherry Pie x Citral Glue)", which
  gives a structure but says Super Lemon Haze and plain Cherry Pie.

So `parents` is `unknown` until a breeder source settles the structure and the names. If founders accept the rosin
review's structure with the flower sources' names, the tree would be (Silver Lemon Haze x Forbidden Fruit) x (NYC
Cherry Pie x Citral Glue).

The Theory dispensary page (theorywellness.org) lists "Lilac Diesel x Lilac Diesel Bx3", a backcrossed seed line,
so it isn't used for the original's parents. Ethos also sells an autoflower version (RBX2 Auto); that is out of
scope (P1) and not this node.

`reported_type: sativa-dominant` from the three Highest Critic reviews (one's text says "Sativa dominant hybrid").
No effect is named by two sources, so `effects` is empty.
