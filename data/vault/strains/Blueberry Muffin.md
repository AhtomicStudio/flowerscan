# Blueberry Muffin

## Curator notes
Humboldt Seed Company's own 2026 seed guide lists Blueberry Muffin as a feminized "Signature Strain", "Indica
Dominant", with the current seed line described as a backcross (Bx10 x BBM#4) built on Blueberry Muffin x Purple
Panty Dropper x Razzle Berry. The Theory dispensary page (theorywellness.org) gives the plain cross: Purple Panty
Dropper x Razzle Berry, bred by Humboldt Seed Company. The parents here follow that cross; the backcrossing in the
current seed line isn't modelled (the catalog doesn't give its structure).

Theory calls it "an indica" while the breeder says indica-dominant; the breeder's word is used.

Search snippets also showed a "Blueberry x Purple Panty Dropper" version, but only from a page that turned out to be
a menu (no strain data) and from a low-quality SEO blog, so there's no usable second version and the note is not
marked disputed.
