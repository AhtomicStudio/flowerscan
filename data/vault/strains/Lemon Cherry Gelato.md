# Lemon Cherry Gelato

## Curator notes
Found as a bag seed in a 2016 pack of Gelato #33 seeds and popularised in California by Backpack Boyz (High
Times). The pollen parent is unknown, so the second parent is `unknown`. High Times notes that many databases
call it a Sunset Sherbet x GSC cross; it says that describes the family, not the documented discovery, so that
version isn't used.

The seed came from a pack of Gelato #33 *seeds*, so strictly its seed parent is a #33 plant, or the population
those seeds came from. Linked to `Gelato #33` as the sources write it.

`reported_type` is unknown: the profile calls it a "balanced-to-indica-leaning hybrid", which spans two of our
values. `breeder` is empty because Backpack Boyz selected and popularised it rather than bred it.
