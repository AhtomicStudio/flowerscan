# King Louis

## Curator notes
Two reviews give OG Kush x LA Confidential and tag it indica dominant. One calls it "King Louis" (the name on the
sales list), the other "King Louie XIII" with the same lineage. They're likely the same plant, but no source says
so, so the XIII spelling is not an alias yet; founders can add it.

Breeder: the 2021 review credits Green Man Cannabis, the 2020 review says unknown, so `breeder` stays empty.
"King Louis OG" by 710 Labs is listed by another review as a "clone only mystery" with no lineage; it is not linked
to this node.

Effect tag: `relaxed` (2021: "relaxing mind and body"; 2020: "relaxation").
