# Gelato Cake

## Curator notes
All three sources give the same two parents. Both Highest Critic reviews write "Wedding Cake x Gelato #33" (the
order used here); Seeds Here Now writes "Gelato #33 x Wedding Cake". T-007 had dropped this strain because the one
listing found then returned 404.

**Breeder is unsettled**, so `breeder` stays empty: both Highest Critic reviews name Elev8 Seeds as the original
breeder, while Seeds Here Now calls the origin unclear and only suggests Seed Junky Genetics. Search results also show
other seed companies selling lines under this name; they weren't researched and are not this node.

`reported_type: indica-dominant` rests on the reviews' category tags, not on breeder text, so it is weak. Seeds Here
Now's table calls it a plain hybrid.
