# Gas Face

## Curator notes
A Seed Junky Genetics cross (both sources name the breeder). The structure follows The Highest Critic (2025):
"(Face Off OG x Kush Mints) x (Biscotti x Sherb bx)". "Sherb bx" is linked to the `Sherb BX1` node.

The Theory page (theorywellness.org) writes it differently: "Face Mints x (Biscotti x Sherbet)", and describes the
second half as a Biscotti x Sherbet backcross. That fits the Sherb BX reading, and "Face Mints" is probably the
Face Off OG x Kush Mints plant, but no source says so, so Theory backs only the type and the effect here. A founder
should confirm before verifying; if Face Mints turns out to be something else, this becomes `disputed`.

Indica-leaning in both: the review's tag ("Indica Dominant") and Theory's text ("indica hybrid"). Effect tag:
`relaxed` (the review calls it "relaxing", but not heavy; Theory: "calm and relaxing physical effects").
